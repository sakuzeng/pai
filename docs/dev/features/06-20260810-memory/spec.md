# 06-20260810-memory · spec

2026-08-10 brainstorm 定稿（四问拍板记录见 [README](README.md)「候选方案与确认」）。

## 背景与问题

pai 现在的「持久指令」只有 `loop.SYSTEM_PROMPT` 一个硬编码常量——换个项目跑，
模型对项目一无所知；上一轮会话学到的东西（构建命令怎么跑、这个仓库的坑在哪）
全部随进程消失。阶段 2 让对话能跨轮，阶段 3 要让**知识能跨会话**。

## 目标（做什么）

### 1. `core/memory.py` —— 分层指令发现与加载

**发现顺序**（拼接不覆盖，越晚读到越靠近对话，照官方语义）：

1. `~/.pai/PAI.md`（用户级，所有项目）
2. 从**文件系统根向下到 cwd** 的每一级目录里的 `PAI.md`
3. 每一级目录里的 `PAI.local.md`（同目录内排在该级 `PAI.md` **之后**）

即：向上遍历收集、**反序**拼接。cwd 之下子目录里的文件**不加载**（官方也不加载，
等模型自己 `read_file` 时才看见——pai 靠现有工具就有这个能力，不需要新机制）。

**`@path` 导入**：
- 相对路径相对**含导入的那个文件**解析（不是 cwd）——这条错了会在嵌套目录里全面失灵；
- 递归展开，**最大深度 4 跳**（官方数字），超深度不抛异常，留一行提示；
- **环检测**（A 导入 B、B 导入 A 必须终止）；
- **跳过代码块与行内代码**：`` `@README` `` 是字面文本，`@README` 才是导入；
- 缺文件不抛——留一行「(未找到 @path)」，指令加载不该弄挂 agent。

### 2. 自动记忆的存储与加载

- 目录：`~/.pai/projects/<key>/memory/`，`<key>` 由 **git 仓库根**决定
  （同仓库的 worktrees/子目录共享一份，官方语义）；不在 git 仓库里则用项目根路径。
  key 用路径 hash（与 REPL 历史同一套做法）。
- `MEMORY.md` = 索引，**每会话加载，前 200 行或 25KB，先到者为准**（官方数字，照抄）；
  超出部分不加载，且要留一行明确提示被截断了（官方没提示，pai 加——静默截断最坑）。
- 主题文件（`debugging.md` 等）**不在启动时加载**，模型要用时 `read_file` 按需读。

### 3. 注入点（问 1 选 B）

指令与记忆拼成**一条 user 消息**，插在 system 之后、用户任务之前：

```
[system: SYSTEM_PROMPT] [user: 分层指令 + MEMORY.md] [user: 任务] …
```

### 4. 压缩后重注入（问 1 选 B 的必做代价）

`compact()` 重建 `[system] + [摘要] + [保留尾部]`，指令消息在第一条 user 位置，
**必然被摘掉**。所以压缩之后必须：**重新调用 `instructions()`（从磁盘重读）**，
把指令消息插回 system 之后。从磁盘重读而不是复用启动时的字符串——官方原话就是
「从磁盘重新读取」，好处是用户中途改了 `PAI.md` 立即生效。

这条是本功能**唯一一个不做就是 bug** 的点（长会话静默失效），验收必须有测试。

### 4. `remember` 工具（问 3/4 选 A）

- `remember(topic: str, fact: str) -> str`：写 `<memory>/<topic>.md`（追加），
  并在 `MEMORY.md` 索引里保证有一行指向它。
- `topic` 要做**文件名净化**（`../` 与绝对路径必须挡掉——工具参数是模型生成的，
  这是唯一一处模型能指定写盘路径的地方）。
- 写入后发 `MemoryWritten(topic, path, bytes)` 事件；loop 把它落进会话 JSONL（可审计）。
- 与 `ask_user_question` 一样，工具本身不抛——出错回字符串。
- **`once` 与 REPL 都注册**（写回不是交互模式独有的，与 ask 不同）。

### 5. `/memory` 命令（REPL）

列出本次会话实际加载了哪些文件（路径 + 行数）与自动记忆目录位置。
官方 `/memory` 的最小版；它也是调试利器——「指令没生效」第一步就是看文件到底加载没有。

## 验收标准

- 分层顺序、`local` 在后、`@` 导入的四条规则（相对路径基准 / 深度 4 / 环 / 代码块内不导入）
  各有测试；缺文件不抛。
- `MEMORY.md` 200 行与 25KB 两条上限各有测试（含「先到者为准」的交叉用例）与截断提示。
- **压缩后重注入**：e2e 测试——超线触发压缩，断言压缩后的下一次请求里指令消息仍在，
  且内容取自**当时磁盘上的**文件（测试中途改文件，断言新内容生效）。
- `remember` 的路径穿越防御有测试（`../../etc/x` 必须被挡）。
- `once` 与 REPL 两条装配路径都有测试；`./test.sh` 全绿全离线。
