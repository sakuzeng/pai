## 一、中文 IME（最值得跑；feature 12 spec 第 11 条，至今零真人验证）

1. 在输入行用拼音打一段中文，中途按退格改字。
   - 过：候选框跟着光标走，退格删掉的是一个汉字不是一个字节。
   - 不过：候选框飘在别处 / 退格后出现半个字 / 光标位置与视觉不符。
2. 中英混输一行（如 `把 read_file 的 offset 改成 1`），按 Home / End / ←→ 移动。
   - 过：光标每一步落在字符边界上，中文一次跳两列。
   - 不过：光标停在汉字中间，或移动一次跳错格数。
3. 输一行长到需要折行的中文，继续打字。
   - 过：折行位置稳定，不闪。
   - 不过：每打一个字整块重排/闪烁。

## 二、resize（feature 38 evidence 第 4 条：状态行按事件重算宽度而非按 resize）

1. 让模型输出一个表格（例如问它「用表格列出 pai 的权限模式」），
   然后拖动窗口由宽变窄、再变宽。
   - 过：表格跟着重排；变窄时单元格出现 `…`，变宽后内容回来。
   - 不过：表格不动 / 出现横向溢出把行冲乱 / dock 被画到错误的行。
2. 在 agent 正在跑的时候 resize。
   - 过：dock 三行（分隔线、输入行、footer）始终在屏幕最后三行。
   - 不过：出现重影、阶梯、或 dock 跑到中间。

## 三、颜色与主题

1. 浅色主题的终端里跑一次。
   - 过：文字都看得清；标题的青蓝、代码块的绿、灰色框线都不糊。
   - 不过：某种颜色在浅底上几乎看不见（记下是哪一种）。
2. `NO_COLOR=1 pai`。
   - 过：一个转义符都没有，但结构还在（标题下划线、`•`、代码块框线）。
   - 不过：出现乱码，或结构也一起没了。

## 四、鼠标（feature 16 的 ★ 悬案：拖选卡顿成因至今未确诊）

1. 让屏幕上有几十行内容，用鼠标拖选一大段。
   - 过：拖动跟手，松开后能 Cmd/Ctrl+C 复制到剪贴板。
   - 不过：拖动卡顿（请记下终端名与大致行数——这条至今没人复现出稳定条件）。
2. 滚轮上滚再下滚。
   - 过：滚的是 pai 的 transcript，footer 出现「已上滚」。
   - 不过：滚出了终端自己的 scrollback（说明鼠标上报没生效）。

## 五、退出与恢复

1. 干活干到一半 Ctrl+C，再 Ctrl+D 退出。
   - 过：屏幕原样还给 shell，主屏留一行「会话存哪了」。
   - 不过：屏幕留着 pai 的残影，或终端状态坏了（提示符错位、输入不回显）。
2. `pai --resume` 接着上一次。
   - 过：上一轮的对话回来了，能接着问。
   - 不过：报错，或对话回来了但设置没跟着回来（这一条已知，见 TODO）。

## 六、规则与记忆（与 `--llm` 冒烟互补）

1. 在项目里放一个 `.pai/rules/x.md`，带 `paths: ["src/**"]`，内容写一条好验证的
   规矩（如「改 src 下的文件时，回复必须以「遵命」开头」）。让模型改一个 src 下的文件。
   - 过：回复真的以「遵命」开头（说明 path-scoped 规则进了上下文）。
   - 不过：没生效（先用 `/memory` 看规则有没有被加载）。
2. 让模型 `remember` 一件事，退出，重开，问它记不记得。
   - 过：记得，且 `/memory` 里能看到那篇。
   - 不过：不记得（先看 `~/.pai/memory/` 下文件在不在）。
