## 真实探针（claude 2.1.239）

场景：scratchpad 建 `skill-probe/.claude/skills/` 下三个 skill——
`probe-alpha`（正常）、`probe-broken`（frontmatter YAML 故意写坏）、
`probe-dirname`（frontmatter `name: totally-different-name` 与目录名不一致）。

P1 · 列表探针（"List every custom skill available…"）：

- `probe-alpha` 按目录名 + description 正常列出。
- `probe-dirname` 按目录名 `probe-dirname` 列出，frontmatter name 未出现——
  证实文档「命令名来自目录名，name 只是显示标签」。
- ⚠️ `probe-broken` 照常列出，description 显示为正文首段
  （"When loaded, reply with exactly: BROKEN-TOKEN-5522"）。官方排障节说
  「frontmatter 格式不正确 → 元数据为空 → Claude 没有 description 来匹配」，
  实测被另一条规则（description 省略时回退正文第一段）覆盖，列表里与正常
  skill 无异。后果：frontmatter 写坏是静默的，正文首段顶上去反而更难发现。

P2 · 按目录名调用：`claude -p "/probe-dirname"` → 返回 `DIRNAME-TOKEN-7741`，符合预期。

P3 · 按 frontmatter name 调用：`claude -p "/totally-different-name"` →
也返回了 `DIRNAME-TOKEN-7741`。⚠️ 与文档「frontmatter name 不会改变你在 `/` 后
输入的内容」不符。机制未查明：可能是 `/totally-different-name` 未命中命令表、
整句进了模型，模型再经 Skill 工具按显示名解析成功——只有实测事实，别编解释。
