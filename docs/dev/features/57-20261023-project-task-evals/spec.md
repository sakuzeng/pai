# 57-project-task-evals · spec

依据档案四项实际单选定稿：完整历史快照、仅离线、相关回归与独立判据、默认开发集且保留集显式选择。

## 交付范围

六题分开发/保留两组各三题，每组覆盖 locate/fix/tests。同一历史问题的变体不得跨组；报告分组，不混出一个“泛化成功率”。
完整快照指目标提交的运行源码、原有测试、依赖/构建配置保留，不裁剪成模块项目。移除 docs/dev、knowledge、refs、旧 evals、Git 历史、agent 指令和配置、个人环境与运行工件，逐文件记录移除集合；用新建空 Git 元数据提供项目根，不把父提交或参考修复暴露给被测 workspace。
起点用完整 commit/tree id 固定；修 bug 从真实修复的父提交出发，参考解仅采用已验证的目标文件变化。查实现、补测试从已交付历史提交出发，后者的错误实现是明确标记的评分探针，不冒称真实历史 bug。

- development/fix：参数 JSON 键序导致路径 deny 匹配失效；起点 4ef6043f1d6ea453416d2ef2b530aa78b8e15339，参考 a8bac67b2393d908cb46c91e51f3e5ab034b0757，仅允许 core/tools/fs.py。

- holdout/fix：无参 resume 必须只选当前 cwd 的会话，显式 id/路径仍能跨目录；起点 41d7174d8263d75e9c2f7fd14f67b8f620abce1f，参考 9e84081a9faf82b1fa57950417fdc2c8e6047a12，仅允许 core/session.py。

非 fix 题起点为文档审计基线 9937c0288b731f5ae3fd333a7e422642c1e045d9。六题均经离线可达性验证，没有因模型成绩调题；最终 freeze.json 逐题保存实际任务与哈希。

## 材料与隔离

案例元数据、外部测试、参考产物和错误实现放 evals/project_tasks；它们不复制进 agent 工作区。快照由本地 Git 对象生成，不联网拉取，不依赖当前 dirty 内容。检查 archive 路径、软链/硬链与目标目录，避免写出根目录。
准备结果包含原 commit/tree、保留文件的逐文件哈希和移除路径清单。只允许清单中声明的文件变化，查实现仅 answer.json；修 bug 不许删改已有测试；补测试不许改生产代码/已有测试/配置。新软链、不存在的根或未知案例明确失败。
评分用独立副本和受控 HOME、环境，隔离 pytest 祖先配置、插件、目标仓库 conftest；断言从历史 src 导入，不能误用当前 editable 安装的 pai。相关历史测试在评分目录中复制执行，不让候选改变判据。评分进程不接收 API key；各子进程有有限截止时间。
配置/目录隔离不是系统级沙箱，也不声称能抵抗恶意测试代码；本轮面向可审计的编码任务产物。

## 判分

locate 核对 JSON 的路径与符号；目标源码存在且符号可验证，其他文件必须不变。
fix：原始状态必须在外部行为断言上失败，参考实现与相关历史回归必须全过；收集错误、语法错误和超时不算“成功复现 bug”。实现只可改变声明的源码文件。
tests：只运行新增测试时正确版本全过、实际收集且无跳过；每个预置错误版本都必须由新增测试中的行为断言杀死，异常导入/收集错误不算。原有相关回归另在正确版本验证，不能靠既有测试替新增测试杀死错误实现。
判分同时保存状态、JUnit/输出与判据；没有 API 或正常 agent 结束状态，本轮不输出 completeSuccess/modelSuccess 数字。
参考解由本地程序在 tmp_path 中安装并评分，明确标记 reference_contract，不伪装成模型运行。负例包括空/全跳过/导入错误/越界修改/删测试/软链，以及错误来源导入。

## 入口与冻结

增加 ./eval.sh --project-tasks，默认只离线核对 development。--split holdout 或 --split all 为显式选择，输出两组独立结果；本入口拒绝 --llm，不接入真实跑批。
提供显式冻结动作，记录案例 prompt、允许文件、源码 commit/tree 与过滤策略、评分器/参考解/错误探针、实现文件及 Python/依赖版本；默认运行先检查已冻结清单，漂移时报错，不悄悄刷新。
六题冻结仅在全体离线契约通过后写入版本库；源码在版本库内，不重复提交整仓复制物。临时材料只写 tmp_path，手工可检查报告写 pai_playground；必要输出复制入本档案 evidence。
保留集没有调用 API；它的本地评分契约验证不等于模型已经见过题。来源是公开/本项目历史，训练污染未知，不宣称盲测或统计泛化保证。

## 非目标与验收

不改 agent loop、工具、权限策略、模型配置或提示词，不新增真实模型调用，不自动提交/推送 57。56 的本地整合已另行完成。
六题各自参考解通过与无效产物被拒；两条历史 bug 确认原始红/参考绿；导入原始 src 与配置隔离有注入反证；默认不触达保留集、显式选择生效、错误参数与冻结漂移被拒。
新功能按 plan TDD 留实际红/绿，标准完整 ./test.sh 全量回归通过后写四问复盘，再宣告离线交付。真实项目效果和后续模型预算保留为未完成范围并登记 TODO。
