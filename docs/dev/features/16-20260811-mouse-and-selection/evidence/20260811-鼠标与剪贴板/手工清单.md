# 手工清单：真实鼠标字节（动工前必须补）

合成鼠标事件被 macOS 辅助功能权限挡住（见[说明.md 第 2 条](说明.md)），
所以下面这些**只能真人动一次鼠标**。它们是 feature 16 的**设计输入**，不是验收项。

跑法：

```sh
python3 docs/dev/features/16-20260811-mouse-and-selection/evidence/20260811-鼠标与剪贴板/probe_mouse.py /tmp/mouse.log
```

窗口会进备用屏并分三段提示，按提示动鼠标即可；结束后看 `/tmp/mouse.log`。

- [ ] **C 段（只开 1003）**：同样只移动 —— **测到 0 条，但结论未定**：
      不能排除「用户当时没真的移动指针」。若确系 iTerm2 不上报无按键移动，
      则 **1003 相对 1002 是买了个空**（hover 高亮做不出来）——这条要再确认一次。
- [ ] **D 段**：单击一次、按住拖一小段、滚一格滚轮。要记下来的：
