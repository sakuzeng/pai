# Feature 56 · 本轮验收范围

用户原话：「帮我进行测试验收」。

本轮验证当前工作区的完整离线回归、新增评测入口，以及既有真实基线的工件/指标/产物。
运行环境：Python 3.9.6，pytest 8.4.2；当前分支 feat/56-task-evals，原有未提交改动保留。

可选真跑问题原文：「这次验收是否重新调用真实模型？」

- 候选 1：「复用已有真实记录，本轮只重跑离线验收（推荐）」。
- 候选 2：「重新跑一轮真实 3×3，沿用此前预算」。

提问后先执行不依赖回答的离线验收；尚未收到新的付费真跑选择，不把默认预选当作用户回答。
若无新增付费授权，本轮复用原始九次真实会话并独立重判产物，不另调真实 API。

用户选择原文：「复用已有真实记录，本轮只重跑离线验收（推荐）」。
选择已明确回传；本轮使用该范围，未新增真实模型调用。
