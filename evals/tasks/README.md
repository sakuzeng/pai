# 三个固定任务

feature 56 首轮任务集；用户选择专门构造的小型 Python 仓库，不能外推成实际 pai 项目开发成功率。
每题 case.json 固定 prompt，workspace 是模型可见的初始项目；reference 为离线评分契约的参考解，grader 是模型工作目录外的判据。

- locate：标签规范化实现定位，结果必须是 text_rules.py 的 slugify。
- fix：整除和零条目时多算一页，外部测试同时覆盖普通与非法参数。
- tests：clip 的普通值、边界和反向范围测试；每个错误实现都须出现行为失败。

初始仓库和评分器在真跑前冻结并记录 SHA-256；既有测试不可删除或改写。题目构造数据，不冒充真实会话。
